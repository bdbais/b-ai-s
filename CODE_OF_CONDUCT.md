# Codice di condotta / Code of Conduct

B-AI-S vuole essere un posto accogliente per chiunque, a prescindere da esperienza, provenienza, identità o opinioni.
*B-AI-S aims to be welcoming to everyone, regardless of experience, background, identity or opinions.*

## Ci impegniamo a / We commit to

- essere gentili e pazienti, soprattutto con chi è alle prime armi;
- criticare le idee, mai le persone;
- accogliere punti di vista diversi;
- riconoscere il lavoro altrui.

## Non sono accettati / Not acceptable

- insulti, molestie, linguaggio discriminatorio;
- attacchi personali o trolling;
- pubblicare dati privati di altre persone senza consenso.

## Segnalazioni / Reporting

Per segnalare un comportamento inaccettabile contatta il maintainer tramite [bais.info](https://bais.info) o con un messaggio privato su GitHub a @bdbais. Le segnalazioni sono trattate con riservatezza.

Questo codice si ispira al [Contributor Covenant](https://www.contributor-covenant.org/).
